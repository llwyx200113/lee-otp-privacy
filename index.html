Last updated: November 12, 2026 · Applies to version 1.0.0 and later

一句话：你的两步验证密钥只存在你自己的浏览器里。我们没有任何服务器，也没有任何方式看到你的密钥、账户或验证码。

1我们收集哪些数据

不收集。本扩展没有账号系统、没有统计埋点、没有崩溃上报、没有广告 SDK，也不会向任何服务器发送你的使用数据。

数据类型是否收集
两步验证密钥（TOTP / HOTP secret）仅保存在本机，不上传
账户名称、发行方、备注仅保存在本机，不上传
浏览记录、访问过的网站不收集
个人身份信息（姓名、邮箱、电话）不收集
位置、设备标识、IP不收集
使用行为、点击流、崩溃日志不收集

2数据存在哪里

所有密钥与设置都通过浏览器提供的 chrome.storage 接口保存在本机浏览器配置目录中。卸载扩展时，这些数据会随扩展一同被浏览器删除。

如果启用主密码，密钥会先用 Argon2 从你的密码派生出加密密钥，再以密文形式保存；密码本身不会被保存，也不会离开本机。

3什么时候会联网

  • 除下一条的时钟校准外，不发起任何网络请求。验证码由本机密钥按 RFC 6238 算法计算，不需要网络。
  • 打开弹窗时（以及点击「校准时间」时），会向 https://www.google.com/generate_204 发一次空的 HEAD 请求，只用于读取服务器时间、修正本机时钟偏差（TOTP 依赖准确时间）。该请求不携带任何账户、密钥、验证码或页面内容，返回体为空。
  • 1.0.0 版本未启用任何把密钥送出本机的功能：云备份（Google Drive / OneDrive / Dropbox）已移除入口，浏览器账号同步（chrome.storage.sync）的开关也已关闭，密钥只写入本机存储（chrome.storage.local）。若后续版本启用上述任一功能，必须由你主动开启并确认，在你操作之前不会发生任何上传。

4是否与第三方共享

不共享、不出售、不转让。本扩展不集成任何第三方分析、广告或数据服务。

In one line: your two-factor secrets stay in your own browser. We have no servers, and no way to see your secrets, accounts or codes.

1What we collect

Nothing. There is no account system, no analytics, no crash reporting, no ad SDK, and no usage data is sent anywhere.

Data typeCollected

Browsing history / visited sitesNot collected
Personal identifiers (name, email, phone)Not collected
Location, device IDs, IP addressNot collected
Usage behaviour, clickstream, crash logsNot collected

2Where data is stored

All secrets and settings are kept in your local browser profile via the chrome.storage API. Uninstalling the extension removes them along with it.

If you set a master password, secrets are encrypted with a key derived from it using Argon2. The password itself is never stored and never leaves your device.

3When it goes online

  • Without cloud backup: never. Codes are computed locally per RFC 6238 and need no network.
  • "Sync time" sends one request to Google's public time endpoint. It returns the current time only and carries no account data.
  • Version 1.0.0 does not enable anything that sends secrets off your device: cloud backup (Google Drive / OneDrive / Dropbox) has no entry point, and browser account sync (chrome.storage.sync) is switched off. Secrets are written to local storage only (chrome.storage.local). If a later version enables either feature, it will require you to turn it on explicitly; nothing is uploaded before you do.

4Third parties

No sharing, no selling, no transfer. The extension bundles no third-party analytics, advertising or data services.

6Your control

  • Delete any account at any time — deletion is immediate and irreversible
  • Export a backup file whenever you want to take your data elsewhere
  • Uninstall the extension to remove all local data
  • Turn off autofill and the extension will not write to any page

This extension is not directed at children under 13 and does not knowingly collect any information from them.
